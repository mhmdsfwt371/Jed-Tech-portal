# بوابة الفريق التقني — أفاقي جدة

**النسخة الحالية: شوف `version.json`** · الدليل الكامل جوه البوابة في تبويب «الدليل»

لينك واحد للفريق كله: منه بيفتح كل أداة بيشتغل بيها، ومنه بشوف أنا شغل الفريق بالأرقام.

**اللينك:** `https://mhmdsfwt371.github.io/afaqy-portal/`

## إيه ده؟

صفحة ثابتة على جيتهب. مفيش سيرفر، مفيش قاعدة بيانات، مفيش فايربيز، ومفيش تسجيل دخول للبوابة نفسها.

جواها أربع صفحات:

| الصفحة | لمين | بتعمل إيه |
|---|---|---|
| الأدوات | الفريق كله | الأدوات التلاتة الأساسية في الأول — مخطط توزيع الحساسات، ومساعد الإنتجريشن، وكانفال — وبعدهم ماي أفاقي وبرو والبريد، وبعدهم باقي الأدوات. كل أداة بتفتح في تاب جديد بحسابها العادي |
| البيانات | المدير | بتطلّع أمر جاهز لكلود كروم لكل فترة، وبتقرا الرد اللي بيرجع |
| المؤشرات | المدير | المؤشر الأول لكل مهندس، وإجمالي الفريق، والمقارنة بين الفترات |
| الدليل | الكل | شرح كل صفحة بالتلات لغات، وعليه رقم النسخة، وبيتطبع — أي ميزة جديدة بتتكتب هنا الأول |

## الحاجة اللي لازم تتفهم الأول

**البوابة مش بتكلم ماي أفاقي.** اتجرّب يوم ٢٩ أكتوبر ٢٠٢٦: سيرفر ماي أفاقي بيقبل الطلبات من موقع ماي أفاقي نفسه
ومن الجهاز المحلي بس، وبيرفض أي موقع تاني — ومنهم جيتهب. فالبيانات بتيجي كده:

1. البوابة بتطلّع أمر لكلود كروم بتواريخ الفترة
2. كلود كروم بيشتغل **جوه** ماي أفاقي وبيقرا المهام
3. بيرجّع النتيجة **بصيغة احنا اللي حددناها** (`afaqy-crm-tasks/v1`) — مش بأسماء خانات ماي أفاقي
4. بتلصق الرد في البوابة، وهي بتتأكد منه وبتحسب

ولأن الصيغة بتاعتنا، لو ماي أفاقي غيّر حاجة جوه، البوابة ما بتتكسرش. التفاصيل في `docs/data-format.md`.

---

## الروتين الشهري

1. **البيانات ← ١:** اختار طول الفترة (ربع، نص سنة، سنة) وعددها
2. **٢:** افتح ماي أفاقي في كروم وسجّل دخول. دوس «نسخ الأمر» جنب الفترة، والصقه في كلود كروم
3. **٣:** الصق الرد أو ارفعه ملف. لو اتقسم أجزاء ارفعهم كلهم — بيتجمعوا لوحدهم بالـ id
4. لو الفترة مكتوب عليها **«ناقصة»** يبقى عدد المهام اللي وصلت أقل من اللي ماي أفاقي قال عليه. ما تعتمدش على أرقامها

## البيانات بتتحفظ فين

على الجهاز والمتصفح اللي رفعها بس. مفيش ولا حاجة بتتبعت لأي حد — الحارس بيرفض أي طلب شبكة في الصفحة غير
`version.json` بتاعها. «تصدير نسخة احتياطية» عشان تنقلها لجهاز تاني أو تحتفظ بنسخة.

---

## قواعد مش قابلة للتفاوض

**ما تخترعش.** الأمر بيمنع كلود كروم يخمّن أي مسار. يستخدم نفس الطلب اللي ماي أفاقي بيبعته ويغيّر التاريخ والصفحة بس.

**قراءة بس.** ولا زرار بيكتب أو بيعدّل في ماي أفاقي.

**الأرقام الناقصة ما تتعرضش على إنها كاملة.** الفترة الناقصة عليها تحذير فوق أرقامها.

**مفيش أسرار في المستودع.** المستودع عام. مفيش توكن ولا كلمة سر ولا مفتاح — الحارس بيدوّر عليهم.

---

## «مؤشراتي» — كل موظف يشوف أرقامه هو بس

من غير حساب ولا كلمة سر: إشارة في المتصفح بتشتغل جوه ماي أفاقي بدخول الموظف نفسه، بتقرا «مهامي» — وماي أفاقي نفسه
ما بيديش فيها غير مهام صاحب الدخول — وبتفتح البوابة بمؤشراته لكل ربع. الأرقام بتفضل على جهازه، ومفيش حاجة بتروح لأي
خادم. الإعداد مرة واحدة من صفحة «مؤشراتي». التفاصيل في القرار العاشر.

## الأدوات وحدات

الأدوات الأربع — مخطط الحساسات ومساعد الإنتجريشن وكانفال وقارئات أفاقي — بتشتغل **جوه البوابة**، تحت شريطها، وكل واحدة
بتفضل مفتوحة على حالها وانت بتتنقل بينهم. الكود بتاع كل أداة في مستودعها؛ أي تحديث فيها بيظهر هنا على طول. ماي أفاقي
وبرو والبريد لينكات، لأنهم بيرفضوا يتعرضوا جوه صفحة تانية.

## دليل المستخدم لكل نسخة

كل نسخة ليها دليلها في `docs/manual/` — عربي وإنجليزي وأردو، كل لغة قسم كامل لوحدها، وعليه رقم النسخة وتاريخها
و«الجديد فيها». بيتولّد من نفس نصوص تبويب الدليل وقت ختم النسخة، فمستحيل يختلف عن اللي جوه البوابة، والنسخ القديمة
بتفضل زي ما هي. الفهرس في `docs/manual/README.md`.

## للي هيطوّر

ابدأ من `docs/START-HERE.md`، والوكلاء (كلود كود وكودكس) بيقروا `AGENTS.md`.

```bash
npm run verify        # الاختبارات والحارس — لازم أخضر قبل أي دفع
npm run bump 5.1      # ختم نسخة جديدة في كل مكان (بعد كتابة release/next.json)
npm run preview       # ملف واحد في dist/ للمعاينة
git config core.hooksPath .githooks   # مرة واحدة: الحارس قبل الدفع وفحص عنوان الالتزام
```
