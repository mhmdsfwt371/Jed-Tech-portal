# ADR-0091 — The pointer's light on everything you can press; one credit wording

| | |
|---|---|
| **Status** | Accepted (the technical manager: «the pointer moving does not light what it stands on»; «write my name the right way, in the right form») |
| **Date** | 2026-11-07 |
| **Version** | v9.08 |

## Decision
- Everything you can press — buttons, pills, menu links, cards, tool cards, table rows, alerts, numbers, pipeline stages, folds —
  gets a soft light that follows the pointer, a lit edge and a small lift; table rows a lit start edge. It is painted as a
  background layer so it never fights the other effects; it is off on touch screens and when the device asks for reduced motion.
- One credit wording everywhere: «فكرة وتصميم وتطوير: محمد صفوت» · «Powered by Mohamed Safwat — idea, design & build».
  «Powered by» is followed by the person who made it, never by the tool's own name. Authorship, not ownership (ADR-0090).
