# ADR-0004 — البيانات على الجهاز

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-10-29 |
| **النسخة** | v5.0 |

## السياق
المهام تحمل أسماء موظفين وعملاء. المستودع عام والصفحة مفتوحة لأي حامل للرابط.

## القرار
ما يُرفع يُحفظ في IndexedDB في المتصفح الذي رفعه وحده؛ لا يُرسل لأي جهة. نسخة احتياطية تُصدَّر وتُستعاد يدويًّا.

## العواقب
- فتح الرابط من جهاز آخر لا يكشف شيئًا.
- مسح بيانات المتصفح يمسح المؤشرات — النسخة الاحتياطية هي الحماية.

## الحالة
يُراجَع مع القرار 0001.
