# ADR-0016 — الملف واللوحة كما في التصميم المعتمد

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-10-29 |
| **النسخة** | v7.3 |

## السياق
اعتمد المدير تصميم الشاشات الأربع (ملف المهندس، ملف قائد الفريق، الهاتف، لوحة المدير) وطلب تنفيذه. كانت البوابة تحمل
الأقسام كلها، وينقصها ما يلي.

## القرار — ما نُفّذ
- **الملف:** زر «تحديث من ماي أفاقي» وإعداد الإشارة مطويًّا فوق البطاقة؛ أزرار الفترة (الشهر / الربع / ستة أشهر) تقلب المقارنة
  كلها — البطاقات والمتوسط و«فريقي»؛ أشرطة المنجزة في «فريقي» نسبةً إلى الأعلى؛ تنبيها «يحتاج نظرة» و«تحسّن واضح»
  بقواعد معلنة (`docs/kpi-factors.md`).
- **اللوحة:** شريط ستة أرقام (المنجزة أولًا)، ترتيب الجدول بالمنجزة أو الوسيط أو المفتوحة، أشرطة المنجزة، ومقارنة الفترات
  أعمدةً فوق جدولها.
- **الهاتف:** الشبكات تتكيّف بعرض الهاتف؛ لا شاشة منفصلة.

## لم يُنفَّذ، ولماذا
- «اثنا عشر شهرًا مقابل التي قبلها»: الفترة السابقة تقع خارج ما تقرؤه الإشارة، فصارت النافذة الثالثة ستة أشهر مقابل الستة قبلها.

## الحالة
نُفّذ. التصميم على لوحة التصميم يبقى مرجعًا، والبوابة الحية هي الأصل.
