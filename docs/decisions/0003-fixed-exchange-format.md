# ADR-0003 — صيغة تبادل نملكها

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-10-29 |
| **النسخة** | v5.0 |

## السياق
كلود كروم يستطيع إعادة صفوف ماي أفاقي كما هي، لكن أسماءها غير موثقة، وبعضها مكتوب خطأً على الخادم
(`maintenenceTime`، `Inovices`، `DropDwon`)، وقد تتغير دون إعلان.

## القرار
الأمر يطلب صيغة ثابتة `afaqy-crm-tasks/v1` بحقول نحن سمّيناها، والتوحيد (الحالة إلى `open/done/cancelled`،
والوقت بالإزاحة) يحدث عند كلود كروم ويُوثَّق في `notes`.

## العواقب
- البوابة وتعريفات المؤشرات مستقرة مهما تغيّر ماي أفاقي.
- كل حقل جديد = صيغة جديدة برقم جديد، والقارئ يقبل القديمة والجديدة.

## الحالة
صائب ما دامت كل فترة تُرفع دون تعديل في البوابة.
