# ADR-0023 — الإرشاد التفاعلي الدائم في صفحة مؤشراتي

| | |
|---|---|
| **الحالة** | معتمد |
| **التاريخ** | 2026-10-30 |
| **النسخة** | v8.10 |

## الدافع

المهندس يحتاج تعليمات فعلية عند إنشاء إشارة «مؤشراتي» وتشغيلها من ماي أفاقي، وقد يحتاج الرجوع للشرح بعد أول استخدام أو عند تغيير جهازه. الشرح المكتوب المطوي وحده لا يكفي.

## القرار

يوضع زر «إرشادي خطوة بخطوة» ثابت في أعلى صفحة «مؤشراتي» قبل وصول البيانات وبعدها. يفتح حوارًا من خمس مراحل، مع أزرار السابق والتالي والإغلاق واختيار الكمبيوتر أو أندرويد أو آيفون. الإرشاد يحافظ على خطوات المتصفح الأصلية: سحب الإشارة على الكمبيوتر أو نسخ رمزها للأجهزة المحمولة، ثم تسجيل الدخول في ماي أفاقي وتشغيل الإشارة من داخل نطاقه. تعرض المرحلة الأخيرة وجود بيانات ملف محفوظة **ولا تدّعي أن عملية السحب اكتملت للتو**. لا يتغير تخزين IndexedDB ولا الكود الذي يقرأ ماي أفاقي.

## الضمانات

- لا يقرأ الحوار بيانات ماي أفاقي ولا يرسل بيانات لشبكة خارجية من البوابة.
- لا يضيف Backend أو تسجيل دخول أو Firebase.
- يُعاد فتحه في أي وقت، حتى بعد ظهور KPI، ولا يغيّر أي بيانات عند التنقل بين خطواته أو عند إغلاقه.
- اللغات الثلاث، الوضع الداكن، الجوال، لوحة المفاتيح وحالة تقليل الحركة مدعومة بالتصميم الحالي.
