# 0025 — إدارة روابط الأنظمة المشتركة

يخزن `systems.json` الروابط والتصنيفات المشتركة. تقرأه البوابة من الشبكة أولاً مع نسخة مخبأة وبيانات مدمجة بديلة. صفحة منفصلة للإدارة تقرأ الملف وتعدله عبر GitHub Contents API بعد إدخال مفتاح محدود صلاحياته إلى المستودع، دون حفظ المفتاح. تستخدم SHA الملف لمنع استبدال تغيير متزامن. ينشر GitHub Pages الملف للفريق بعد نجاح النشر. المجلد عام والروابط عامة.
