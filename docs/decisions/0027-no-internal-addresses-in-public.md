# ADR-0027 — لا عناوين داخلية في المستودع العام؛ الروابط الخاصة على الجهاز

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-10-30 |
| **النسخة** | v8.21 |

## السياق
المستودع عام. ملف الروابط المشتركة (القرار 0025) نُشر فيه رابط دخول VPN لمشروع حكومي بعنوان IP ومنفذ، وظهر كذلك في `config.js`.

## القرار
- حُذف الرابط من `systems.json` و`config.js`، وأُعيدت كتابة التاريخ لإزالة العنوان من الكوميتات القديمة مع بقاء الكوميتات ورسائلها وتواريخها.
- **القاعدة 25 في الحارس:** أي رابط منشور يشير إلى عنوان IP خام أو اسم داخلي (‎.local وما شابه) يُرفض، وأي عنوان IP في رابط داخل الملفات أو الوثائق يُرفض.
- **«روابطي الخاصة»** تحت أنظمة الشركة: عناوين داخلية تُحفظ على الجهاز فقط (IndexedDB)، تقبل http/https بلا بيانات دخول، تُفتح بلا مُحيل،
  وتنتقل مع النسخة الاحتياطية الكاملة (القاعدة 24).

## ما بقي
نقل `systems.json` إلى مستودع بيانات مستقل حتى لا يملك مفتاح صفحة إدارة الروابط صلاحية الكتابة على البوابة كلها — يحتاج إنشاء المستودع
ومفتاحًا له من صاحب الحساب.
