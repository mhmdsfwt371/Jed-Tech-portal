# ADR-0019 — الأوزان، والتثبيت، والتحديث التلقائي، وعلامات «؟»

| | |
|---|---|
| **الحالة** | معتمَد — الأوزان مقترح استشاري للاعتماد، قابلة للتعديل |
| **التاريخ** | 2026-10-29 |
| **النسخة** | v8.1 |

## السياق
العدد الخام يساوي بين «إظهار مركبات» و«ربط مع وصل». المدير طلب وزنًا لكل نوع مهمة ولكل نشاط مع العملاء، لفريقي ما بعد البيع
والبحث والتطوير في جدة، وتطبيقًا يُثبَّت على أندرويد وآيفون وويندوز ويتحدّث وحده، ودليلًا وعلامة «؟» لكل شيء.

## القرار — الأوزان
**المنهج: الوزن بالتعقيد والقيمة، لا بوقت القفل.** بيانات أكتوبر أثبتت أن وقت القفل يقيس الانتظار: «تجهيز زيارة صيانة» وسيطها
٧٠ ساعة و«مهمة يدوية» ١٢ دقيقة. الوزن بالوقت يكافئ من ينتظر لا من يعمل.

| الوزن | الفئة | المعيار |
|---|---|---|
| ١ | إجراء إداري سريع | بلا تشخيص ولا طرف خارجي |
| ٢ | تعامل مع العميل أو تشخيص | رد، بلاغ صيانة، فحص، مشكلة تطبيق، استعلام ربط |
| ٣ | ربط بجهة خارجية أو تنسيق ميداني | وصل، مدينتي، رافد، نقابة، إيقاف بزيارة فني، كونفيجريشن، CAN |
| ٥ | عمل متعدد المراحل | تدريب عميل، نقل أجهزة |

أنشطة العملاء: دعم ١، برمجيات ٢، API ٣، ربط حكومي ٣ — **تُحسب حين تصير Done فقط**.
**النقاط = Σ (المنجزة في الفترة × وزن نوعها) + Σ (الأنشطة المنجزة × وزن تصنيفها).** بجانب العدد لا بدله.
**على بيانات أكتوبر:** كل أنواع ما بعد البيع موزونة، والأوزان تغيّر الترتيب حين يختلف خليط العمل — المقصود بالوزن.

### الحوكمة
الفئة والسبب معلنان لكل نوع؛ المسجّل للنفس يبقى ظاهرًا؛ مراجعة كل ربع؛ أي تعديل يُعتمد بـ`weights.json` في المستودع (الحارس ٢٢).

## القرار — التطبيق
- **تثبيت:** زر «تثبيت التطبيق» — أندرويد وويندوز بنافذة المتصفح نفسها، وآيفون بخطوات «إضافة إلى الشاشة الرئيسية».
- **تحديث تلقائي:** كل إصدار يُنشر يصل وحده: فحص عند الفتح وكل ١٥ دقيقة وعند العودة للتبويب، ثم إعادة تحميل **مرة واحدة لكل
  إصدار** ما لم يكن المستخدم يكتب — وإلا زر التحديث. لا حلقة أبدًا (مُختبَر).
- **«؟»:** بجانب كل عنوان صفحة وكل قسم رئيسي، تفتح شرحًا بلغة القارئ. الحارس ٢٣ يرفض صفحة بلا «؟» أو «؟» بلا نص في أي لغة.
- **الدليل:** يُولَّد مع كل إصدار من نصوص الدليل نفسها (الحارس ١٢)، فلا يتأخر عن البوابة.

## ما ينقص
قائمة أنواع مهام فريق البحث والتطوير في ماي أفاقي — الموزون منها الآن ما ظهر في البيانات (كونفيجريشن، CAN، أخرى).
