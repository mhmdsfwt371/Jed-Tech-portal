# ADR-0024 — المتصفح التجريبي المتحرك في دليل «مؤشراتي»

| | |
|---|---|
| **الحالة** | معتمد |
| **التاريخ** | 2026-10-30 |
| **النسخة** | v8.12 |

## الحاجة

الدليل التفاعلي المكتوب لم يكن كافيا للموظف. المطلوب إظهار حركة الماوس في نافذة متصفح ليتعلم موضع الضغط وسحب الإشارة إلى شريط إشارات المتصفح، أو لمس الأزرار على أندرويد وآيفون، مع إمكانية إعادة المشهد في أي وقت.

## القرار

تُرسم نافذة محاكاة مرئية داخل نفس حوار الإرشاد السابق. يحدد `tourDemoPlan()` مسار الماوس أو الإصبع في كل مرحلة، وتحركه الرسوم المتكررة في CSS مع ظهور مؤشر نقر ونتيجة توضيحية. على الكمبيوتر يُعرض سحب الإشارة نحو شريط الإشارات، وعلى الجوال تتابع لمس الشاشة حسب الجهاز. زر «إعادة حركة الماوس» يعيد العرض من البداية.

## الحدود

- التمثيل **محاكاة لا شاشة حقيقية ولا تحكم عن بعد**. ليس ممكنًا للبوابة تحريك مؤشر نظام التشغيل أو النقر في نافذة MyAFAQY خارج نطاقها.
- تُظهر الشاشة التوضيحية بيانات نتائج فارغة «—» لتجنب اختلاق عدد مهام أو مؤشرات فعلية. النص يوضح أن النتائج تظهر بعد أن يشغل الموظف الإشارة في ماي أفاقي بنفسه.
- الإشارة البرمجية الفعلية لا تتغير، ولا يوجد Backend أو Firebase أو تخزين بيانات جديد.
- يدعم اللغات الثلاث وتقليل الحركة، وقابل لإعادة الفتح في أي وقت.
