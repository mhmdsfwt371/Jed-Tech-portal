# صيغة التبادل — `afaqy-crm-tasks/v2`

العقد بين كلود كروم والبوابة. الأمر (`buildPrompt()` في `core.js`) يطلب هذه الصيغة بالحرف، والقارئ (`parseDataset()`)
يقبلها، ويقبل `v1` السابقة أيضًا. أي تغيير هنا = رقم صيغة جديد. الحقول مبنية على التقاط ٢٨ أكتوبر ٢٠٢٦ (`crm-api.md`).

## الشكل
```json
{
  "schema": "afaqy-crm-tasks/v2",
  "range": { "from": "2026-10-01", "to": "2026-10-31" },
  "extractedAt": "2026-11-02T09:00:00+03:00",
  "taskGroupId": 100001,
  "source": { "endpoint": "POST https://crmbackend.afaqy.sa/Task/GetMyTasksGrid", "doneInRangeTotal": 1608, "openTotal": 51, "pageSize": 20 },
  "people": [ { "id": "…", "nameEn": "…", "nameAr": "…", "teams": ["…"], "branchCode": "2" } ],
  "tasks": [ { "…": "انظر الجدول" } ],
  "part": "1/3",
  "notes": ["…"]
}
```

## ما يحويه الملف
- **كل مهمة أُنجزت داخل الفترة** (بمرشح `completedOn` على الخادم) — وعددها كما أعلنه الخادم في `doneInRangeTotal`.
- **كل مهمة أُنشئت داخل الفترة وأُنجزت بعدها** — لحساب نسبة الإنجاز للمهام التي وصلت في الفترة.
- **كل مهمة مفتوحة الآن** — وعددها كما أعلنه الخادم في `openTotal`.
- **الأشخاص** الذين يظهرون مسؤولين أو منشئين، بفرقهم ورمز فرعها.

## حقول المهمة
| الحقل | من ماي أفاقي | إن غاب |
|---|---|---|
| `id` | `id` | الصف يُستبعد ويُعدّ |
| `title` · `type` · `typeId` | `title` · `taskType` · `taskSettingId` | فارغ |
| `statusId` · `state` | `statusId`؛ `state` = `cancelled` إن `isCancelled`، وإلا `done` إن ٣، وإلا `open` | `open` |
| `createdAt` | `createdOn` بالإزاحة | الصف يُستبعد |
| `createdById` | `createUserId` | |
| `assigneeId` | `assigneeId` | الصف يُستبعد |
| `completedAt` | `closeDate` للمنجزة فقط | لا تدخل حساب المدة |
| `moduleId` | `moduleId` — ١٤٦ يعني مهمة من بريد عميل | |
| `customer` | `customerTag` | `null` |
| `bucket` | الوعاء: `done` · `open` · `toDo` | |

## قواعد القراءة
- **لا يُخترع شيء.** الصف الناقص يُستبعد ويُعلَن عدده.
- **الوقت بلا علامة منطقة يُقرأ UTC** دائمًا، أيًّا كانت منطقة الجهاز — هكذا يرسله ماي أفاقي (تحقّق ٢٩ أكتوبر ٢٠٢٦ على الشاشة).
  والأيام والأرباع تُحسب بتوقيت السعودية بعد ذلك.
- **«من البريد» = `moduleId == 146`**، لا منشئ المهمة.
- **الأجزاء تُدمج بالمعرّف**، والأشخاص بالمعرّف.
- **الاكتمال** = المنجزة داخل الفترة ≥ `doneInRangeTotal`، والمفتوحة ≥ `openTotal`.
- **البيانات التجريبية** تحمل `"sample": true` ومفتاحها يبدأ بـ `sample:`.

## `team.json` — `afaqy-team/v1` (من v7.2) — القرار 0015
```json
{ "v": 1, "schema": "afaqy-team/v1", "people": { "<رقم ماي أفاقي>": { "position": "مهندس ما بعد البيع", "positionEn": "After-sales engineer", "leaderId": "<رقم القائد>" } } }
```
أرقام ومناصب وقادة فقط. أي حقل آخر — اسم، هاتف — يرفضه الحارس ويُسقطه القارئ.

## `afaqy-me/v2` (من v7.0) — القرار 0014
```json
{ "schema": "afaqy-me/v2", "user": { "id": "…", "name": "…" }, "extractedAt": "…", "since": "…", "months": 12,
  "people": [ { "id": "…", "nameEn": "…", "nameAr": "…", "teams": ["…"], "branchCode": "2", "h": true } ],
  "tasks":  [ { "i": "…", "c": "…", "d": "…", "s": "open|done|cancelled", "m": 179, "o": false, "b": "open|toDo|done", "a": "…", "t": "…" } ] }
```
`a` المسؤول عن المهمة. `t` لمهام صاحب الملف المفتوحة وحدها. `h` = في هيكل صاحب الملف (تحته). تُسلَّم برسالة، والقارئ يقبل v1 أيضًا.

## `afaqy-me/v1` — حقل `t` (من v6.9)
عنوان المهمة، **للمفتوحة فقط** (حتى ٨٠ حرفًا)؛ للمنجزة لا يُرسل. يُعرض لصاحبه في «شغلي المفتوح الآن» ولا يغادر جهازه.

## `rdTaskIds` (من v6.8)
قائمة معرّفات المهام في طابور «البحث والتطوير» (١٢) للفترة. إن وُجدت يظهر عمود «بحث وتطوير»؛ والملفات الأقدم تُقرأ بدونه.

## تقارير الفترة — `afaqy-crm-reports/v1`
ملف ثانٍ للفترة نفسها، من «نسخ أمر التقارير» (القرار 0012):

```json
{
  "schema": "afaqy-crm-reports/v1",
  "range": { "from": "2026-10-01", "to": "2026-12-31" }, "branch": "2", "extractedAt": "…",
  "techPoints": [ { "month": "2026-10", "listCount": 65, "rows": [ { "technicianId": 0, "employeeId": 0, "nameEn": "…", "nameAr": "…",
                    "installedDeviceCount": 0, "maintainedDeviceCount": 0, "…": "عشرون حقلًا عدديًّا — TECH_FIELDS في core.js" } ] } ],
  "afterSales": { "rows": [ { "id": 0, "name": "…", "open": 0, "pending": 0, "done": 0, "total": 0 } ] },
  "notes": []
}
```

القارئ يأخذ الحقول المسمّاة فقط؛ أي مكافأة أو هاتف أو تقييم في الملف يُسقط ولا يُخزَّن.

## `v1`
الصيغة الأولى (٢٩ أكتوبر ٢٠٢٦) ما زالت تُقرأ: كانت تحمل `fromEmail` و`assignedToGroup` و`completedById` صراحة. لم تُرفع
بها بيانات حقيقية قبل أن يكشف الالتقاط أن ماي أفاقي لا يحمل علامة المجموعة ولا «من أنجز» في الصف.

## تسليم «مؤشراتي» — `afaqy-me/v1`

ما تسلّمه إشارة «مؤشراتي» للبوابة (القرار 0010)، في جزء العنوان بعد `#me-`: حرف الترميز (`z` مضغوط، `j` بلا ضغط)،
ثم نقطة، ثم JSON بترميز base64 الآمن للعناوين.

```json
{
  "schema": "afaqy-me/v1",
  "user": { "id": "<UserId من رمز الدخول>", "name": "<UserName>" },
  "extractedAt": "<ISO>", "since": "<بداية الاثني عشر شهرًا، ISO>", "months": 12,
  "tasks": [ { "i": "<id>", "c": "<createdOn>", "d": "<closeDate للمنجزة>", "s": "open|done|cancelled", "m": <moduleId>, "o": <true إن أنشأها الموظف نفسه>, "b": "done|open|toDo" } ]
}
```

لا شيء غير ذلك: لا رمز الدخول، ولا العناوين، ولا العملاء، ولا الأسماء، ولا معرّف أي شخص — `o` نعم أو لا فقط. البوابة تمسح العنوان فور القراءة.
